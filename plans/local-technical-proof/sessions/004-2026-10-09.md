## Gaps Closed

1. The installed native adapter rewrote developer/system roles. A public local model capability registration selects the native role-preserving adapter and proves all four roles at the actual mock boundary. No upstream source or provider dispatcher was replaced.
2. The SDK discarded a raw refusal before post-call validation. A supported HTTPX response hook validates the bounded raw envelope before native parsing; the native failure hook also normalizes actual model timeout to 504.
3. Invalid redaction could be classified as general unavailability. Transformation prevalidation now selects the distinct transformation-failure action; regression cases deliberately use opposing failure settings. Actual HTTP authentication/schema rejection tests close a separate fail-open classification gap.
4. Docker accepted loopback port declarations but omitted NAT bindings on its internal-only bridge. Host supervision now provides a loopback-only, fixed-destination encrypted passthrough when inspection shows missing bindings. It does not terminate TLS or permit external destinations. Containers retain the internal network and pull-never startup.
5. Added real launcher recovery/reset tests, installed-package gateway supervision, bounded retry of transient operation-status reads and explicit fixed-count collection enforcement. Mutations are never automatically repeated.
6. Expanded privacy scans from sensitive fragments to actual submitted clean/sensitive fixture text, deterministic outputs, all run credentials, both stores, spools and service logs. Authored corpus and restricted credential inputs are excluded from observation scans; authorized-retention tests use separate stores.
7. A gateway restart while the runtime was stopped changed container IP allocation. Supervision now reinspects/rebinds host forwarding after starts and restarts. Connection accounting uses directly connected non-default container subnets, so startup needs no peer DNS and restarted local peers are not mistaken for external dependencies. A unit regression checks changed local peers, loopback and external destinations.
8. Distinguished strictly parsed runtime context-expiry/missing-context Problems from caller schema rejections sharing HTTP 422. Only the operational output-context cases use the captured fallback configuration; authentication and ordinary caller rejections still cannot fail open. Unit regressions cover both context codes.
9. An earlier runtime fixture submitted several setup mutations before their runtime acknowledgements. A real acknowledgement writer could cause the next write to return an uncommitted 503. Runtime and gateway setup now serialize publication/onboarding by authenticated application receipts, matching the CLI default, with unchanged storage/deadline limits and no mutation retries.
