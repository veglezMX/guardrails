## Decisions Made

- Continue in the assigned persistent worktree and branch. The user authorized a commit after completing Phase 2; no push or integration was requested.
- Retain the existing Compose project and image tags for compatibility; the artifact manifest records actual rebuilt image identities. The optional management service uses loopback port 8443 and its own SQLite directory.
- Runtime acknowledgements in this phase are authenticated **test receipts**, permitted by the phase gate. They do not establish real runtime application. Unacknowledged mutations remain pending across restart.
- Required stages and types must occur together in a sufficiently strong check. Governance does not compose checks into a weaker substitute or combine policies.
- A competing SQLite writer may receive the configured bounded-busy 503 before acquiring the transaction; otherwise a stale revision returns 409. The concurrency test proves exactly one new revision commits and explicitly verifies the stale request returns 409 after contention ends. No automatic mutation retry was introduced.
- The existing smoke runtime remains a separate explicit fixture. Management integration does not seed workload/policy/binding rows through deployment files.
